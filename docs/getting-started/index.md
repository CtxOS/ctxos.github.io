# Getting Started

CtxOS is an Ubuntu-based operating system.

## Requirements

- 64-bit x86 or ARM64 hardware
- UEFI-compatible firmware
- USB drive for ISO installation
- Internet connection recommended

## Installation

Download the latest ISO from:

https://ctxos.github.io/iso/

Write the ISO to a USB device and boot from it.

## Package repository

CtxOS packages are provided by:

https://deb.ctxos.github.io/
